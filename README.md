# Evening Planner

Evening Planner is a CSC 4184 prototype for managing a daily calendar and fitting activities into open evening time.

## Run locally

Use Node.js 20.9 or newer. From the repository root:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The prototype stores events in the browser. Open it in a fresh private window to start with the example schedule. No account or environment variables are required.
